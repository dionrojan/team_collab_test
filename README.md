# Team Collaboration Test

Welcome to our team portfolio project! 

## About This Project
This is a collaborative web development repository that aims to help people understand Git and GitHub, as well as how to work effectively with a team. You can practice these skills by adding your own portfolio folder to this project!

## Technologies Used
* HTML5
* CSS3
* JavaScript

## How to View
* First, install Git on your machine.
* Copy the link to this repository by clicking the green **Code** button on GitHub and copying the HTTPS link.
* Open a terminal in the folder of your choice and run: 
  `git clone https://github.com/dionrojan/team_collab_test.git`
* Simply open the `index.html` file in your web browser to view the main navigation hub!

## How to Contribute
* **Never work on the `main` branch directly.**
* Create a new feature branch for your work (e.g., `portfolio/your-name`).
* Add your folder, commit your changes, and push the branch to GitHub.
* Open a **Pull Request** on GitHub to merge your code into `main` after testing everything!
