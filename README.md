## 🚀 Portfolio Features

- 🎨 **Animated Hero Section** — Profile photo with glowing cyber ring, floating skill tags & dynamic typing text
- 🌐 **Interactive Particle Canvas** — Mouse-reactive particle network background built in HTML5 Canvas
- 💻 **Skills Section** — Python, SQL, C, and Java with clean topic-based cards
- 📁 **Projects Showcase** — SkillSprint featured project with full modal overview
- 🏆 **Certifications Gallery** — Real certificate images with interactive modal viewer
- 🖥️ **Cyber Terminal** — Fully interactive hacker-theme console with custom commands
- 📬 **Contact Form** — Live form connected to Gmail inbox via Formspree
- 📱 **Fully Responsive** — Works perfectly on mobile, tablet, and desktop
